# SQL Commands

## SQL Retrieval

### Basic structure:
```sql
SELECT column
FROM table;
```
where `column` is what you want to "take" from the table. <BR>
for example by having `SELECT *` Which means you select __ALL__ data from the
table.

where `table` is what table you want to take the infomation from.
for example:
```sql
SELECT *
FROM contacts;
```
which in turn would return all data within the contacts table

#### Selecting from Specfic Columns
By doing the following
```sql
SELECT first_name, last_name
FROM contacts;
```
This Retrieves only the infomation specficed (in this case it would be the first and last names of each contact)

#### Selecting with Filters 
This allows you to take data from contacts only if that contact has that infomation.
Here's a working example:
```sql
SELECT *
FROM contacts
WHERE user_id = 1;
```
which in turn would only show if the contact has the `user_id` of 1

You can also select with multiple conditions for example:
```sql
SELECT *
FROM contacts
WHERE user_id = 1
AND first_name is "John";
```
Which would return all conatacts that has the `user_id` of 1 AND they have the 
`first_name` of "John"
